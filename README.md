# محاكي XIM Matrix

تطبيق ويب يحاكي الميزات الأساسية لجهاز **XIM Matrix** (محوّل الماوس ولوحة المفاتيح إلى يد تحكم)،
ويعرض بصرياً كيف تتحوّل حركة الماوس إلى عصا تحكم يمنى، مع ميدان تصويب لتجربة الإعدادات.

> هذا محاكٍ تعليمي يعمل داخل المتصفح فقط، ولا يرسل أي إدخال إلى جهاز ألعاب حقيقي.

## الميزات

| الميزة | الوصف |
|---|---|
| **المترجم (Translator)** | تحويل سرعة الماوس إلى قيم عصا يمنى ‎[-1, 1]‎ بشكل مستقل عن معدل الإطارات |
| **إعدادات Hip / ADS منفصلة** | حساسية، نسبة Y/X، تنعيم، وتعويض منطقة ميتة لكل وضع، مع تبديل تلقائي عند الضغط على LT |
| **منحنى الباليستيك الذكي** | محرر منحنى تفاعلي (سحب، إضافة بالنقر المزدوج، حذف بالزر الأيمن) مع مؤشر حي لسرعتك الحالية |
| **تعويض المنطقة الميتة** | دائري أو مربع، مع زر لمطابقتها تلقائياً مع المنطقة الميتة للعبة |
| **إعادة تعيين الأزرار** | ربط أي مفتاح أو زر ماوس بأي زر في يد التحكم |
| **يد تحكم افتراضية** | عرض حي للأزرار والعصي والزنادات |
| **محاكاة اللعبة** | منطقة ميتة ومنحنى استجابة وسرعة دوران وFOV وتكبير ADS ومساعدة تصويب (إبطاء + تتبع) |
| **ميدان تصويب** | أهداف متحركة، إحصاء الإصابات والدقة |
| **ملفات الإعدادات** | حفظ/تحميل محلي، تصدير واستيراد JSON، وإعدادات جاهزة |
| **وضع اللمس للهاتف** | سحب للتصويب، عصا افتراضية، وأزرار على الشاشة، مع حساسية لمس قابلة للضبط |
| **تمرير يد تحكم حقيقية** | عبر Gamepad API عند توصيل يد تحكم |

## تطبيق أندرويد (APK)

- ملف جاهز للتثبيت: [`dist/XIM-Simulator.apk`](dist/XIM-Simulator.apk) — نزّله على الهاتف، واسمح بالتثبيت من مصادر غير معروفة، ثم ثبّته.
- كل دفع (push) إلى GitHub يبني APK جديداً تلقائياً عبر GitHub Actions (تبويب Actions ← آخر تشغيل ← Artifacts).
- **وضع اللمس**: اضغط على الميدان؛ اسحب بإصبعك للتصويب، والعصا الافتراضية يساراً للحركة، وأزرار الإطلاق وADS وA يميناً. زر ✕ أو زر الرجوع للخروج.
- لوحة مفاتيح أو يد تحكم بلوتوث/USB تعمل أيضاً.

البناء يدوياً (يتطلب Android SDK وJDK 17+):

```bash
cd android && ./gradlew assembleRelease
# الناتج: android/app/build/outputs/apk/release/app-release.apk
```

## التشغيل في المتصفح

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
npm start        # http://localhost:8080
```

ثم انقر على ميدان التصويب لالتقاط الماوس (Esc للخروج).

### الأزرار الافتراضية

- **WASD**: العصا اليسرى · **الماوس**: العصا اليمنى
- **زر الماوس الأيسر**: RT (إطلاق) · **الأيمن**: LT (تصويب ADS)
- **Space**: A · **C**: B · **R**: X · **1**: Y · **Q / E**: LB / RB · **Shift**: L3 · **V**: R3

## مسار الترجمة

```
عدّات الماوس → السرعة → الحساسية → منحنى الباليستيك → نسبة Y/X
→ التنعيم → تعويض المنطقة الميتة → قصّ القيم → العصا اليمنى
```

المنطق موجود في `js/core.js` (دوال نقية بلا DOM)، والواجهة في `js/app.js`.
